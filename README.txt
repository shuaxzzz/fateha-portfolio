## Add your image assets
Copy your actual images into these exact paths (case-sensitive):
```
assets/
├── photo.jpg
├── projects/
│   ├── reviewshield-home.png
│   ├── reviewshield-result.png
│   ├── zus-menu.png
│   ├── educat-dashboard.png
│   ├── pastry-home.png
│   └── fraud-game.png
└── certificates/
    ├── data-analyst-python.png
    ├── data-scientist-python.png
    ├── associate-data-scientist-python.png
    ├── gen-ai-champion.png
    └── gold-award.png
```
Keep your existing `assets/logos/` folder too, because the education and organisation sections refer to logo images there.

The HTML/CSS/JS files are ready, but the image files themselves are not included in this ZIP. Replace the sample paths with the exact names of your real images if you use different filenames.

## GitHub Pages
Upload/replace `index.html`, `style.css`, and `script.js` in the same folder as your current site. Upload the `assets` folder and keep the same folder structure. Commit the changes, then refresh the published site. GitHub Pages paths and filenames are case-sensitive.

## Before publishing
- Use screenshots and certificates you have permission to publish.
- Check certificate images for personal identification numbers or private details.
- Do not upload confidential internship documents, client data, credentials, or company source code.
- Add direct repository links to individual projects only when those repositories are public and ready.
